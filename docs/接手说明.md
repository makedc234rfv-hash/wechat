# 接手说明（给执行导出的 AI / 使用者）

用户希望你在本机上使用同一套“读取本地微信 → 按会话与日期导出 → 阅读工作消息 → 写日报/周报”的功能。先检查目录和环境，再做一次小范围导出，不要把笔记本的个人目录照抄到目标机器。

## 1. 部署与检查

- 整包解压，本包的 `app\WeChatExport\_internal` 必须与 `WeChatExport.exe` 相邻。
- 使用 Windows x64；微信应为 `Weixin.exe` 的 4.x 客户端并已登录本人账号。本工具不负责微信登录或跨电脑迁移聊天记录。
- 默认在当前用户的 Documents 和 Windows 登记的“文档”路径下寻找 `xwechat_files`。自定义数据位置可用 `--data-root` 或 `--account`，不要迁移笔记本路径。
- 先运行 `--self-test`；它只用合成数据，不读取真实微信，也不会发起网络连接。
- 从确认过的本人账号，选一天或一个指定会话做真实验证。这里只在打包机器做过离线测试，尚未验证目标电脑微信版本。
- 首次以普通权限运行。若报进程访问拒绝，检查微信与工具是否使用同一 Windows 用户、完整性级别；需要调整权限时先说明原因，不修改系统安全防护。

## 2. PowerShell 命令

在解压根目录运行。所有路径均相对解压目录，不依赖打包机器。

```powershell
$tool = Join-Path $PWD 'app\WeChatExport\WeChatExport.exe'
& $tool --self-test
& $tool --list-accounts
```

`--list-accounts` 只检查目录，不读取进程。若有多个账号，必须由用户确认目标，使用 `--account` 明确指定，不默认挑第一个。

导出一天（示例日期请按用户要求替换；输出目录必须不存在）：

```powershell
& $tool --date 2026-10-27 --output '.\exports\2026-10-27-run1'
```

自定义数据位置：

```powershell
& $tool --list-accounts --data-root 'D:\自己的微信数据\xwechat_files'
& $tool --date 2026-10-27 --account 'D:\自己的微信数据\xwechat_files\实际账号目录' --output '.\exports\指定账号-run1'
```

`--account` 指向含 `db_storage\message\message_0.db` 的具体账号目录；`--data-root` 则是它的父级 xwechat_files。

导出日期范围、周或月：

```powershell
& $tool --start 2026-10-26 --end 2026-10-27 --output '.\exports\两天-run1'
& $tool --kind week --anchor 2026-10-27 --output '.\exports\本周-run1'
& $tool --kind month --anchor 2026-10-27 --output '.\exports\十月-run1'
```

日期起止均包含当天，消息日期固定按北京时间 UTC+08:00；周为周一至周日，月为自然月。不会查询尚未发生的消息。

先列出会话，再选择具体会话：

```powershell
& $tool --list-conversations --output '.\exports\会话列表-run1'
# 本地阅读 exports\会话列表-run1\conversations.json，取准确 id。
& $tool --date 2026-10-27 --conversation '实际会话ID' --output '.\exports\指定会话-run1'
```

可重复传入 `--conversation`，群使用实际群ID。找不到指定ID会报错停止，不会自动扩大到全部会话。若不传该参数，将导出指定日期内的全部本地会话。列会话也需要读取已登录微信并临时解密本地数据库，但不会生成全量聊天归档。

程序的最后一行 stdout 是 JSON 结果，进度输出到 stderr。退出码0表示成功，1表示执行失败，2表示命令参数错误。失败时先看错误，不要把失败导出目录当成成功结果，也不要覆盖重跑；用新的输出目录。

## 3. 导出结果如何阅读

```text
本次输出目录/
  聊天归档/
    index.html
    manifest.json
    归档说明.txt
    会话名__标识/
      YYYY-MM-DD/
        messages.jsonl
        messages.html
        images/ files/ audio/ video/（有对应内容时才存在）
    报表/（HTML及JSON统计）
```

优先用 JSONL 阅读，每行是一条消息，常用字段为 `timestamp`、`conversation_name`、`sender_name`、`direction`、`message_type`、`text`、`attachments`、`warnings`。`direction` 可能为 sent、received、unknown、system；不能猜测未知发送者。需要核实附件时，按实际导出目录及附件元数据解析路径，不要按行号或文件名猜关联。

`manifest.json` 提供数量、缺失媒体及其他异常统计。数据库校验失败时停止导出。快照包含已提交WAL回放，但各数据库逐个读取，不是整个账号跨库同一时刻的事务快照。

## 4. 故障处理

- 找不到微信：先让用户登录 Windows 微信，保持运行。本包不支持手机直接抓取，也不支持 Mac/Linux 原生微信。
- 找不到账号：核实微信设置里的真实文件存储位置，再用 `--data-root`/`--account`；不能凭笔记本路径判断。
- 没有可用数据库密钥、DLL不匹配或校验失败：确认微信版本、登录状态及客户端目录，记录不含密钥的错误；不要注入、修改进程或关闭防护来强行继续。
- 某些数据库版本变更：保留原数据，让用户提供版本号及脱敏错误再适配，不宣称所有4.x版本都支持。
- 日期无消息：先核对北京时间及该电脑是否真的保存了对应历史；0条不等于账号当天没有聊天。
- 正常退出和可捕获失败会清理 `_temporary_snapshot`；强制关闭或断电后，先确认进程退出，再核实并清理本工具输出目录中残留的临时快照，不触碰原微信目录。

## 5. 用来写日报

称呼和署名按用户要求。只写工作相关内容，区分“方案准备”“脚本离线测试”“实际执行”“验收通过”。不把聊天中的口头判断当成现场验证，不把旧日期工作算成当天成果。密码、令牌、私人聊天不写进日报。语音未转写或媒体缺失时如实说明资料范围。

当前任务仅交付工具；本包不预先授权外发聊天归档、发送日报、登录其他账号、安装机器人或修改全局 Claude 配置。用户以后明确要求相应动作时再按范围处理。

## 6. 源码及重建

原核心：`archive_app.py`、`probe.py`、`snapshot.py`、`export_archive.py`、`media.py`、`period_report.py`。本次新增 `wechat_tool.py` 和 `portable_tests.py`，未改写原六个核心模块。底层算法引用来源保留在原 probe.py 顶部注释。

如需自行重建，使用 Python 3.14 x64；源码依赖和构建依赖在 source 下列明。本包便携程序已含依赖，日常使用无需这些步骤。

```powershell
py -3.14 -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r .\source\requirements-build.txt
& .\.venv\Scripts\python.exe .\source\wechat_tool.py --self-test
& .\.venv\Scripts\python.exe -m PyInstaller --noconfirm --onedir --console --name WeChatExport --distpath .\rebuild --workpath .\build-cache --specpath .\build-cache .\source\wechat_tool.py
```

## 7. 给用户的首次反馈

反馈 Windows/微信版本、账号定位是否成功（不回贴账号标识）、离线自检结果、小范围实际导出的消息数及缺失项、输出目录位置。只有真实导出和回读成功后，才说明目标电脑已跑通。
